# Known Issues & Technical Debt

This document tracks architectural improvements and performance optimizations needed for the Tulay Kanban project.

## Architecture & Refactoring
- **Resolved (2026-02-22)**: `frontend/app.js` was split into ES modules (`frontend/api.js`, `frontend/state.js`, `frontend/ui.js`, `frontend/events.js`) with `frontend/app.js` reduced to a bootstrap entrypoint.
- **Resolved (2026-02-22)**: Backend monolith was split from `backend/main.py` into modular routers (`backend/routers/*`) and shared core modules (`backend/core/*`), with `backend/main.py` now acting as a composition root.
- **Resolved (2026-02-22)**: `frontend/events.js` listener orchestration was decomposed into focused submodules (`frontend/listeners/board.js`, `frontend/listeners/task.js`, `frontend/listeners/modal.js`, `frontend/listeners/dragdrop.js`) while keeping `frontend/events.js` as composition root.
- **Resolved (2026-02-22)**: Non-listener board/task/modal state handlers were extracted into service-style modules (`frontend/services/board-service.js`, `frontend/services/task-service.js`, `frontend/services/modal-service.js`) to further reduce orchestration load in `frontend/events.js`.
- **Resolved (2026-02-22)**: Drag-drop and realtime runtime logic were extracted into `frontend/services/dragdrop-service.js` and `frontend/services/realtime-service.js`, with `frontend/events.js` reduced to delegation wrappers.
- **Partially Resolved (2026-02-22)**: Global `window` namespace pollution was reduced by moving `tasks`/`boards` into ES module scope, but UI rendering still relies on duplicate/manual escaping helpers (e.g., `escapeHtml`) that should be replaced with safer DOM-first patterns.

## Backend & API
- **Partially Resolved (2026-02-22)**: Board reordering now uses a batched endpoint (`POST /api/workspaces/{ws_id}/boards/reorder`). Column reordering still fires N individual `PUT /api/columns/{id}` calls and needs a batched column reorder endpoint.
- **Client-side Filtering**: `loadMyTasks` manually groups data in JS. This logic should move to API query parameters (e.g., `?assignee=me&group_by=status`).
- **Partially Resolved (2026-02-22)**: IDs are generated by the backend/database for persisted records (UUID defaults in SQLAlchemy models). A legacy client-side `Date.now()` task ID generator remains in frontend code and should be removed.

## UI & Performance
- **Template Bloat**: HTML strings are hardcoded in JS. These should be migrated to HTML `<template>` tags or a lightweight component library.
- **Manual Escaping**: `innerHTML` usage requires manual `escapeHtml`. Moving to `.textContent` or the native Sanitizer API is safer.
- **Layout Thrashing**: Sidebar overflow logic uses expensive manual `offset` calculations. This should be replaced with CSS/Container Queries.
- **Date Handling**: Custom date formatting logic should be replaced by `Intl.DateTimeFormat` for better performance and localization.
